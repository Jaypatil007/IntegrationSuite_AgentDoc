# Product Roadmap

The development of the **CPI iFlow Analysis Agent** is an ongoing journey to provide deeper, faster, and more intelligent integration analysis. Below is our current roadmap detailing upcoming features and expected milestones.

## Upcoming Milestones

### Q3 - Advanced Document Generation and Auto-Documentation
- **Auto-Documentation Generator:** Automatically generate full HTML/PDF architecture and design documents directly from an iFlow with one click.
- **Export to Draw.io:** Export the generated graph models explicitly to editable format (e.g., Draw.io, Mermaid.js markdown) so architects can directly insert them into enterprise wikis.

### Q4 - Multi-iFlow Analysis
- **Multi-iFlow Comparison:** Compare two distinct versions of the same iFlow, explicitly highlighting what integration logic changed between versions.
- **Cross-iFlow Dependency Mapping:** Analyze how multiple external API calls from one iFlow impact the processing flow of downstream integrations.

### Q1 (Next Year) - Optimization and Execution Simulation
- **Optimization Simulation:** Simulate payload routing based on inferred logic and provide estimated latency/bottleneck metrics.
- **CI/CD Pipeline Integration:** Plugins for GitHub Actions and Azure DevOps to run the parsing and error validation tools automatically on pull requests.

> [!TIP]
> We actively adjust the roadmap based on user feedback. Have a feature request? Reach out to our maintainers!
